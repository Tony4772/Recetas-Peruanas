Sabor Perú

Política de privacidad

Información clara sobre los datos que se usan al explorar y compartir recetas en la aplicación.

Contacto: Para consultas sobre privacidad, escribe a contacto@ebyzom.com.

Última actualización: 18 de noviembre de 2026

Esta política describe cómo funciona la aplicación móvil Sabor Perú (en adelante, “la aplicación”). La versión aquí descrita no necesita una cuenta para utilizar sus funciones.

1. Responsable y contacto

El responsable de la aplicación es su desarrollador. Para consultas sobre esta política o privacidad, escribe a: contacto@ebyzom.com.

2. Datos que recopila la aplicación

La versión actual no solicita datos personales para crear una cuenta y no incorpora servicios propios de analítica, publicidad ni servidores que reciban información desde la aplicación. Tampoco solicita permisos de acceso a ubicación, contactos, cámara, fotos o micrófono.

Las acciones que realizas dentro de la app —por ejemplo, marcar favoritos, cambiar una receta del plan semanal, escribir ingredientes en la lista del mercado o marcar elementos— se mantienen temporalmente en la memoria de la aplicación. No se guardan en una cuenta ni en un servidor. Al cerrar la aplicación o cuando Android finalice su proceso, estas selecciones pueden restablecerse.

3. Compartir recetas o listas

Si eliges compartir una receta o la lista del mercado, la aplicación prepara el texto correspondiente y abre el selector de compartir de Android. El contenido se entrega a la aplicación que tú elijas. Sabor Perú no controla cómo esa aplicación receptora usa o protege la información; consulta la política de privacidad de dicho servicio. No se envía contenido a terceros si no inicias esta acción.

4. Conexión, almacenamiento y conservación

Las recetas y recursos necesarios para mostrar el contenido están incluidos en la aplicación. La versión actual no requiere una conexión a Internet para consultar sus funciones principales ni transmite datos a servidores del desarrollador. Las selecciones temporales descritas arriba desaparecen cuando se reinicia el proceso de la app. El uso de una aplicación externa para compartir se rige por las condiciones de ese proveedor.

5. Seguridad

Como la versión actual no mantiene una cuenta ni envía los datos de uso a servidores propios, no existe un perfil remoto de usuario que gestionar. Recomendamos mantener Android y las aplicaciones instaladas actualizados, y revisar los permisos y políticas de las aplicaciones externas que decidas usar para compartir.

6. Privacidad de menores

La aplicación contiene recetas y herramientas de cocina de uso general. No solicita deliberadamente información personal de menores. Si tienes alguna consulta relacionada con la privacidad, contacta al responsable mediante el correo indicado en esta página.

7. Cambios a esta política

Esta política puede actualizarse si cambian las funciones o prácticas de datos de la aplicación. Publicaremos la versión vigente en esta página y modificaremos la fecha de actualización. Si una actualización incorpora recopilación o uso de datos nuevos, la política se revisará para explicarlo.

8. Contacto

Para preguntas sobre privacidad o esta política, escribe a contacto@ebyzom.com.
